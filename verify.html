Vernen Verification Log

Browser-based verifier. This page runs entirely in your browser. No network calls. No trust in Vernen required. Recomputes the Merkle root from the proof path you provide and compares it to the expected root from this repo.

Algorithm: standard binary Merkle tree, SHA-256, last leaf duplicated when a level has odd length, leaf index determines left/right pairing at each level. See spec.
